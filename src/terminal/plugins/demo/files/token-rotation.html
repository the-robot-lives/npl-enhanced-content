Token Rotation

Every session mints a short-lived JWT and rotates the refresh token per use.

JSON Web Token — a signed, self-describing bearer token. Proof Key for Code Exchange — binds an authorization code to the client. A long-lived grant exchanged for a new access token; retired on every use.

Rotation

Rotation in five lines. 
export function rotate(pair: Pair): Pair {
  const next = mint();
  retire(pair.refresh);
  return next;
}
