Token Rotation — a reading document

Exercises the R/W1 prose elements in the v0.3 element form: a glossary, a chronology, code listings and references. Open this file directly in any browser; reading.html is the same document in class form.

Operators: rotate the signing key on the same cadence as the refresh token.

Glossary

JSON Web Token — a signed, self-describing bearer token. Proof Key for Code Exchange — binds an authorization code to the client that requested it. A long-lived grant exchanged for a new access token; retired on every use.

Rotation

Every session mints a short-lived JWT and a refresh token. A public client proves possession of its authorization code with PKCE. Rotate the refresh token per use[1]: each exchange retires the token that was presented[2]. The framework itself recommends it[1]. The token ttl is a configuration value, not a glossary term.

Code

Rotation in five lines; the shell form below is the same call. 
export function rotate(pair: Pair): Pair {
  const next = mint();
  retire(pair.refresh);
  return next;
}

Disclosures

Signing keys

Rotate the signing key on the refresh cadence; publish both keys during the overlap.

Browser clients keep the pair in an httpOnly cookie.

Native clients

Native clients keep the pair in the platform keychain.
