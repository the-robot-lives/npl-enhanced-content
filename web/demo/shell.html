sem-shell

An interactive shell over a small in-memory file system of SemText documents — the <sem-terminal> core configured with the bundled posix-sh and semtext-demo plugins (see src/terminal/PLUGINS.md). Try ls -l, bat demo/welcome.html, semtext render demo/token-rotation.html, semtext tui demo/token-rotation.html, grep -rn Rotation demo/, open demo/welcome.html. Pipes and redirects work (cat demo/quiz.html | grep -c sem-fact); so do export, alias, history and $?. Arrows recall history; Ctrl+L clears; help lists everything; man ls explains one command.

On open the shell demos itself: the script attribute types a short tour. Escape stops the script and hands you the terminal; the replay button restarts it. With prefers-reduced-motion the whole tour runs instantly. With JavaScript off, the static transcript below is the whole story.
