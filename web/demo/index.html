Reveal — Q→A disclosure

Tokens in localStorage are readable by any script on the page — one XSS away from session theft. Prefer httpOnly cookies or memory-scoped storage.
Refresh tokens rotate per use — each exchange retires the presented token.
Session storage dies with the tab, which shrinks — not eliminates — the theft window. Treat every browser-side token as exposed.

Note — margin view

Long-form prose sits beside the margin note. Refresh tokens rotate per use, so each exchange retires the token that was presented; the access token stays short-lived and the refresh grant issues a new pair. Scope capabilities tightly rather than extending lifetime — a long-lived token is an anti-pattern whatever it is scoped to.
