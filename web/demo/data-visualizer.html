A view that filters columns

Two declared views; the second keeps only the operator columns. Its container id (fleet-views) makes it deep-linkable (spec/data-visualizer.md §10): the Expand and Copy-link chrome mints #dv=fleet-views&view=… links, and the modal reopens from links minted inside it.

Relative files, a declarative join, and the editable default query

One visualizer, the whole phase 4 + 5 story: two buckets fetched from files next to this page (CSV and YAML), a join composing them on the named key column, and the editable default query reading the joined bucket — edit it and re-run (button, Ctrl/Cmd+Enter, or just keep typing; it re-runs as you type). The container id (ops-combined) makes the edited query deep-linkable too (#dv=ops-combined&q=…).

SELECT name, port, zone, latency_ms FROM service-regions ORDER BY latency_ms DESC
