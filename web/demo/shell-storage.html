sem-shell — persistent storage

The same shell as shell.html, but the local-storage attribute persists the whole file tree in the browser. Create files, reload, and they are still here: mkdir -p notes, touch notes/hello.txt, echo remember-me > notes/todo.txt, then reload the page and ls notes. storage status shows the backend and any failed writes; storage reset puts the factory documents back. Mounting is live too: mount lists what a page can attach (local-storage is wired here; an S3 bucket needs https:// and CORS — see man mount).

$ mkdir -p notes
$ echo remember-me > notes/todo.txt
$ storage status
local-storage: 0 failed writes
$ # reload — the tree survives
$ ls notes
todo.txt
